# Цель

dots.tts — это полностью непрерывная 2B-параметровая авторегрессивная система синтеза речи (TTS) на основе flow-matching с поддержкой клонирования голоса, эмоциональной выразительности и мультиязычности. Проект включает готовые к использованию модели (pretrained, self-corrective-aligned, MeanFlow-distilled), CLI, Python API и Gradio демо.

**Статус**: Вендоренный upstream-клон от rednote-hilab (не sitex). Используется как база для экспериментов / интеграции.

## Критерии готовности

- [ ] Модели доступны и загружаются без ошибок
- [ ] CLI `dots.tts` работает для синтеза речи и клонирования голоса
- [ ] Web-демо (Gradio) запускается и функционален
- [ ] Fine-tuning пайплайн готов к использованию (если требуется)

## Политика ответов

- Водитель сам решает: обновление зависимостей, исправление логирования, локальные конфиги, исправление типичных ошибок при запуске (OOM, missing weights, audio format).
- Эскалировать человеку: смена архитектуры кода, upstream sync/merge, изменение лицензии, публикация форков.

## Ограничения

- Python 3.10–3.12, torch 2.8.0+, torchaudio 2.8.0+
- Требует GPU с достаточной памятью для 2B-модели (~8GB+ VRAM)
- Поддерживаемые языки: zh (китайский), en (английский), multilingual (24 языка в бенчмарке)
- Audio: 48 kHz output
